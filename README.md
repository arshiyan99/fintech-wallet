# FinPay Wallet

A responsive front-end demo of a personal wallet dashboard, built with HTML, CSS, and vanilla JavaScript.

## Features

- Dashboard with wallet balance and recent transactions
- Send money and add-money demo flows
- Transaction history with search and type filters
- Profile page with saved preference toggles
- Wallet state saved in the browser using `localStorage`
- Responsive layout for desktop and mobile screens

## Run locally

Open `index.html` in a browser. No build step or package installation is required.

## Project structure

- `index.html` — wallet dashboard
- `transfer.html` — send and add-money demo form
- `history.html` — searchable, filterable transaction history
- `profile.html` — profile details and preferences
- `contact.html` — contact options
- `css/style.css` — application styles
- `js/app.js` — wallet state and page interactions
- `assets/images/` — images used by the interface

## Important

This is a front-end demonstration, not a real financial service. Transfers and top-ups only update the demo balance and transaction history saved in the current browser. No real money is moved.
